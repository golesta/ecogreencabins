# Eco Green Cabins

Static snapshot of https://ecogreencabins.vercel.app/, mirrored on 2026-10-01 to move the site
off the slow DNN host and onto Vercel under this account.

This is the **rendered static output** (HTML/CSS/JS/images) of the site the India team built,
not the original Next.js/React project source. It's enough to host and serve as-is, but future
content/layout changes mean editing these HTML files directly rather than a framework source tree.
If the original project source becomes available, it should replace this snapshot.

## Deploy

Static site, no build step. `vercel.json` sets `cleanUrls` so routes like `/About` resolve to
`About.html`.
